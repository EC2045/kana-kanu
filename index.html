カナーカヌ語 文法

■ 基本語順

SVO（主語 - 動詞 - 目的語）

■ 時制・機能マーカー（動詞に付く数字接尾辞）

記号意味
1現在
2過去
3目的・ための表現

■ 主な単語

単語意味
fk私
dks食べる
rmksりんご
rpsj綺麗、美しい

■ 形容詞

形容詞は名詞の後ろに置く（後置修飾）。

fk dks1 rmks rpsj ＝ 私は美しい（綺麗な）りんごを食べる。

■ 文字について

カナーカヌ語で使用される 1, 2, 3, 4 などの記号は数字ではありません。
これらは文字体系の一部であり、専用フォントでは独自の文字として表示されます。

■ ア補完

子音が3つ以上連続する場合、連続を断ち切るために最小限の1箇所に「a」の音を挿入する現象。
単語が子音2文字のみで構成される場合は、語末に「a」を補う。

■ マジックc

英語のmagic-e（例：mad → made）と同様の仕組み。
単語の末尾に c が来ると、c の前から2番目にあたる子音・母音の読み方が変化し、 c 自体は発音されない（無音化する）。

動詞の時制接尾辞「1・2・3」とは別の語として、数詞は独立した単語（do, ny, xu, wl, je）で表す。

■ 疑問文

■ 場所構文（n...l）

n と l で語を挟むと「〜に／〜で」という場所を表す構文になる。
例：nq04l ＝ ここに（q04 ＝「ここ」）
